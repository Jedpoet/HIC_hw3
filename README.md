# $1 Unistroke Recognizer

以 Python + Tkinter 實作的 $1 單筆畫手勢辨識器，可以自己錄手勢模板，再拿來辨識。

## 如何運行

只用到標準函式庫（`tkinter`、`math`、`json`、`os`），不需要安裝其他套件。

### 使用 uv（推薦）

```bash
uv run main.py
```

> `pyproject.toml` 設定的是 `requires-python = ">=3.14"`，uv 會自動準備符合版本的 Python。

### 直接使用 Python

實測 Python 3.13.14 可以直接執行：

```bash
python main.py
```

或

```bash
python3 main.py
```

> 請確認你的 Python 有附 Tkinter（Windows / macOS 官方安裝檔預設就有；部分 Linux 發行版要另外裝 `python3-tk`）。

## 介面操作

程式開啟後**預設為「辨識」模式**。

```
[ 辨識 ][ 錄製模板 ]  標籤: [______]
┌──────────────────────────┐
│                          │
│          畫布             │
│                          │
└──────────────────────────┘
          狀態 / 辨識結果
     [ 清空 ]  [ 查看模板 ]
```

### 錄製模板

1. 點上方的 **「錄製模板」** 切換模式。
2. 在 **「標籤」** 欄輸入這個手勢的名稱（例如 `1`、`circle`）。
3. 在畫布上用滑鼠左鍵**一筆**畫出手勢。
4. 放開滑鼠後，畫布會顯示經過前處理（重新取樣、旋轉、縮放、平移）的手勢，**紅點為起點**，下方狀態列會顯示已存入及該標籤目前的模板數量。
5. 模板會存進 `templates.json`。同一個標籤可以錄多次，錄得越多變化通常辨識越穩定。

> 沒輸入標籤就畫的話，會跳出提示並丟掉這次的筆畫。

### 辨識手勢

1. 確認上方選的是 **「辨識」**。
2. 在畫布上畫一筆手勢，放開滑鼠後下方會顯示辨識結果與分數。

> `templates.json` 裡還沒有任何模板的話，會提示你先去錄製。

### 查看 / 刪除模板

- 點 **「查看模板」** 會開新視窗，左邊列出所有模板（`標籤 #編號`）。
- 點其中一項，右邊會預覽它的形狀（紅點為起點）。
- **「刪除」**：刪掉選取的模板；**「重新整理」**：重新讀取 `templates.json`。

### 其他

- **「清空」**：清除畫布。
- 筆畫太短（少於 5 個點）會被忽略，請重畫。

## 已知問題

- **數字「1」的辨識準確率偏低。** 推測是前處理少了某些步驟，例如 $1 原論文提到：對「1」這種接近直線的一維手勢做非等比縮放到正方形時，很窄的那個方向會被過度放大，讓形狀失真。目前暫時沒有額外優化。
